# Тревога рядом

Android-приложение с вертикальным домашним виджетом 1×2. Виджет определяет
текущий город, район и область по геолокации телефона и показывает только
локальный статус воздушной тревоги. Во время активной тревоги он также выводит
тип угрозы и опубликованное направление движения из свежих оперативных
сообщений Повітряних Сил ЗСУ.

Версия 1.0.5 также держит постоянный индикатор в верхней строке телефона:
сплошная точка означает тревогу, кольцо — отсутствие тревоги, кольцо с точкой
внутри — статус уточняется. В раскрытой шторке индикатор дополнительно получает
красный, зелёный или янтарный системный акцент.

В проект также входит модуль `wear`: самостоятельное приложение для Wear OS,
которое отдаёт тот же статус циферблатам через `AlarmComplicationService`.
Зелёный статус означает отсутствие тревоги, красный — активную воздушную
тревогу, янтарный — неизвестные или устаревшие данные. Нажатие открывает
экран с городом, временем начала и длительностью тревоги.

## Возможности

- автоматическое определение текущего местоположения;
- обязательный фильтр геолокации: координаты за пределами Украины игнорируются,
  а статус берётся для последнего подтверждённого места в Украине;
- зелёное состояние «Тревоги нет»;
- красное состояние «Воздушная тревога» с длительностью;
- тип угрозы и направление движения во время тревоги;
- пометка официального источника и времени оперативного сообщения;
- автоматическое скрытие оперативной информации старше 10 минут;
- нейтральный текст «уточняется», если свежего сообщения для текущего региона нет;
- защита от устаревшего зелёного статуса при потере связи;
- безопасный сброс статуса после перезагрузки телефона;
- ручное обновление кнопкой на виджете;
- постоянный неснимаемый индикатор состояния в строке уведомлений;
- автоматическое восстановление индикатора после перезагрузки и обновления приложения;
- поддержка изменения размера и добавления в стопку виджетов Samsung;
- источник статуса — официальная карта `map.ukrainealarm.com`;
- источник типа и направления — публичный канал ПС ЗСУ `t.me/kpszsu`.

Композиция виджета построена по золотому сечению: при тревоге вертикальные
зоны распределяются как 1.46 / 2.36 / 1.46 / 0.90 (в сумме 6.18). Приоритет
читаемости и критической информации сохраняется на маленьких экранах.

Оперативный текст дополняет официальный статус тревоги, но не заменяет команды
властей, ДСНС и правила безопасности.

## Сборка

Требуются JDK 17 и Android SDK 35.

```bash
./build-apk.sh
```

APK телефона версии 1.0.5 появится в `app/build/outputs/apk/debug/`.

Wear OS APK собирается отдельно:

```bash
./gradlew :wear:assembleDebug
```

Он появится в `wear/build/outputs/apk/debug/` (версия 1.1.1) и устанавливается на часы один
раз для всех совместимых циферблатов.

Файл `signing/tryvoha-poruch.keystore` нужен для установки будущих обновлений
поверх уже установленной версии. Не публикуйте его отдельно от личного архива.
